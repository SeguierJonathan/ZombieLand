1. Identité visuelle

Logo : version principale, version secondaire, favicon.

Variantes du logo : noir/blanc, monochrome, avec slogan, sans slogan.

Signatures ou icônes associées : favicon, icônes pour réseaux sociaux.

2. Palette de couleurs

Couleur principale : utilisée pour les éléments principaux (boutons, liens).

Couleurs secondaires : pour les éléments secondaires ou surlignages.

Couleurs neutres : fond, textes, bordures, backgrounds.

Couleurs d’accent : pour attirer l’attention (alertes, call-to-action).

Codes couleurs : hex, RGB, CMJN si nécessaire pour print.

3. Typographie

Polices de caractères : titres, sous-titres, corps de texte.

Styles et variantes : normal, gras, italique, capitales, petites capitales.

Tailles de police : h1, h2, h3… p, labels, boutons.

Interlignage (line-height) et espacement des lettres (letter-spacing).

4. Iconographie

Style des icônes : flat, outline, filled…

Taille standard et échelle responsive.

Couleurs ou dégradés appliqués aux icônes.

5. Images et illustrations

Style d’illustration : réaliste, flat, vectoriel, photographique.

Filtres ou traitements : saturation, contraste, style couleur spécifique.

Taille, ratio et positionnement sur le site.

6. Boutons et éléments interactifs

Forme : arrondis, carrés, contour…

Couleur : normal, hover, actif, désactivé.

Typographie : taille, graisse, alignement.

Animation ou transition : hover, click, focus.

7. Formulaires et champs

Input/textarea : bordures, arrondis, couleurs, placeholder.

Validation : couleurs et icônes pour erreur, succès, warning.

Labels et aide : style, taille, position.

8. Navigation

Menu principal : couleur, typographie, hover, actif.

Menu secondaire / footer : mêmes détails.

Style du survol et transitions.

9. Mises en page et grilles

Grille principale : colonnes, marges, gutters.

Breakpoints pour responsive design.

Espacements standard : padding, margin pour sections et blocs.

10. Éléments multimédias

Vidéos : ratio, style de player, overlay.

Animations : micro-interactions, transitions, durée.

Effets spéciaux : ombres, parallax, hover effects.

11. Style des textes spéciaux

Titres, citations, liens : couleur, style, decoration.

Listes : bullets, numérotation, indentations.

Tables : bordures, fond, header style.

12. Accessibilité

Contrastes : couleurs texte/fond selon WCAG.

Taille minimale du texte.

Focus visible sur éléments interactifs.
